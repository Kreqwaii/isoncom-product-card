# ISON — Прототип карточки товара (WooCommerce)

Интерактивный прототип страницы товара (single-product) для магазина систем видеонаблюдения **ISON** (`isoncom.ru`).

## Возможности
- **Конфигуратор комплекта**: динамический пересчёт итоговой стоимости при выборе серии (`Pro`, `Alfa`, `Greko`, `Molk`), количества камер (`2`–`32`), объёма жёсткого диска и дополнительных опций.
- **Галерея и схема подключения**: переключение изображений товара, интерактивная SVG-схема подключения PoE-системы.
- **Адаптивная вёрстка**: корректное отображение на десктопе и мобильных устройствах (`390×844`).
- **Чистый стек**: HTML5, CSS3, Vanilla JS без внешних зависимостей.
